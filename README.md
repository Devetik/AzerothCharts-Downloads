# AzerothCharts Companion

Official Windows installers for [AzerothCharts](https://azerothcharts.com). This repository distributes the companion application; the project source repository remains separate.

## Download

[Download AzerothCharts Companion 0.5.1 for Windows (64-bit)](https://github.com/Devetik/AzerothCharts-Downloads/releases/download/companion-v0.5.1/AzerothCharts-Setup-0.5.1.exe)

[All releases](https://github.com/Devetik/AzerothCharts-Downloads/releases)

Install the companion, connect your AzerothCharts account, and select the WoW saved variables for your account. Install the AzerothCharts addon separately. Use `/reload` in WoW to save local data and load downloaded history.

The companion is free. Community history synchronization depends on the account plan and available scans: Free every 4 hours, Plus every 15 minutes, Premium every minute.

Each release includes the Windows installer, its blockmap and the `latest.yml` update manifest.
