# AzerothCharts Companion

Official Windows installers for [AzerothCharts](https://azerothcharts.com). This repository contains application downloads only; the main application source repository remains private.

## Download

[Download AzerothCharts Companion 0.7.6 for Windows 64-bit](https://github.com/Devetik/AzerothCharts-Downloads/releases/download/companion-v0.7.6/AzerothCharts-Setup-0.7.6.exe)

## Get started

1. Close World of Warcraft and install the companion. You can install it over an earlier companion version.
2. On first launch it looks for World of Warcraft in Program Files (x86) and Program Files. Choose the game version if several are found, or choose your WoW folder manually if needed.
3. The companion installs AzerothCharts automatically. Windows may request permission for the game folder. No saved-variable file selection is needed.
4. Connect your AzerothCharts account and wait for the main banner to show Prices ready before entering WoW. Available Forever Beta realms are prepared without a first WoW save. The preview contains up to six observations per item across 24 hours; full 30-day history follows. Files received while already in game still need `/reload` or a later login. Existing installations: close WoW and click Reinstall AzerothCharts to install addon 0.23.19. The website must be updated for the new preview routes.

Existing saves and account settings are preserved. An existing SuperSniper edition is preserved. The installer is not yet publisher-signed.

Free synchronizes every 4 hours; Plus every 15 minutes; Premium every minute, subject to available scans. The addon and companion are free.
